# Идеи рисунков для карт «Событие»

WAKE UP · подготовлено Лисом по просьбе Димы · 26 сентября 2026 года.

**305 сюжетов — по одному для каждого действующего события, плюс рекомендация для пустой карты.** Это предложения для выбора и генерации, а не новые правила или утверждённый финальный арт. Названия и ID взяты из [действующего каталога](../game/ru/cards/events.md). Удалённые карты не возвращены. «Кофе» описан один раз: его тиражные повторы используют тот же утверждённый рисунок, если автор позже не решит иначе.

Авторские образы «Баланса» (корова на канате), «Экономной поездки» (ослик и богачи) и «Утилизатора» (офисный шредер) сохранены. Остальные сценические детали — предложения Лиса, опирающиеся на эффекты и [пояснения автора](https://github.com/NEO-Wake-UP/wake-up-card-game/blob/main/design/event-design-notes.ru.md). Уже имеющиеся прототипы не заменены. Сюжет не добавляет изображённому персонажу новых игровых возможностей.

[Как генерировать рисунки и собирать карту в Affinity](affinity-event-card-guide.ru.md) · [Обычная рамка](../templates/cards/event-affinity-63x88.svg) · [Рамка для длинного эффекта](../templates/cards/event-affinity-63x88-long.svg).

## С чего начать

Для первых проб особенно хорошо подходят **EV-195 «Баланс»**, **EV-143 «Кофе»**, **EV-087 «Ипотека»**, **EV-095 «Зона комфорта»**, **EV-188 «Налог на существование»**, **EV-220 «Дырявый карман»**, **EV-256 «Забытая заначка»**, **EV-285 «Монета устала»**, **EV-290 «Монета отдыхает»** и **EV-302 «Козёл отпущения»**. У каждого один крупный, понятный визуальный трюк. Выберите несколько удачных первых рисунков как постоянные референсы всей колоды.

## Общий художественный язык

- Рисованная мультяшная карикатура в духе центральной сцены «Экономной поездки»: уверенный тёмный контур, мягкие тени, яркие, но не кислотные цвета, выразительные лица.
- Одна сцена и одна главная шутка. Сначала крупный силуэт, жест и предмет; фон поддерживает их. Избегаем мелких зрителей, сложных графиков и шуток, которые читаются только под лупой.
- Сарказм направлен на абсурд правил жизни: касса важнее человека, богатство притягивает богатство, работа съедает время, привычка принимает решения за хозяина. Иногда просто добрая нелепость.
- Корова, ослик, денежный сейф и ожившая монета могут повторяться как знакомые персонажи, но не нужно превращать каждое событие в одну и ту же сцену. Для повторяющегося персонажа прикладывайте один выбранный референс.
- BABLOS — зелёные игровые банкноты; события — голубые карточки; статусы при необходимости — фиолетовые. Точный печатный номинал и буквенные обозначения лучше добавлять отдельным слоем.
- Рисунок квадратный, без плашек, рамок и текста. Главные детали — ближе к центру. Шутку надо проверить в окне шириной около 54 мм, а не только на полном экране.
- Количество предметов на рисунке не заменяет условие эффекта. Если цифра существенна для шутки, её можно добавить в Affinity; параметры игры берём только из каталога.

## Как использовать строку

Скопируйте её сюжет в шаблон запроса из [руководства](affinity-event-card-guide.ru.md), приложите референс стиля и при необходимости референс персонажа. Скачайте исходный PNG. Назовите файл по ID, например `EV-195-v01.png`, а понравившийся итог — `EV-195.png`. Для поиска нужной карты в этом документе нажмите **Ctrl+F** и введите ID или название.

Для EV-212 строка служит описанием уже существующего прототипа, а не поручением его переделать. EV-311 содержит смысл финала: его художественный тон спокойнее остальной денежной суеты.

## EV-BLANK — пустое событие

Оставить достаточно чистого светлого места, чтобы игроки могли вписать собственный эффект и название. Возможный маленький декоративный образ — карандаш, задумчиво смотрящий на пустой квадрат. Не заполнять всё поле сложной сценой: свобода игрока здесь и есть содержание карты.
