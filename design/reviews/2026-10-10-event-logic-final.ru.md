# Итог проверки логики событий — 10 октября 2026 года

Автор принял EV-167 и EV-343, удалил EV-341, выбрал окончательную формулировку EV-129 и прямо поручил **сохранить все накопленные изменения в основную ветку**. Слияние выполняется через PR #34. Это поручение отменяет предыдущий запрет слияния и включает уже сохранённые 19 эффектов, четыре удаления, ST-009/011/013 и название EV-380 «Сотка».

## Последние утверждённые эффекты

| ID | Название | Эффект |
| --- | --- | --- |
| EV-129 | Олимпиада | Самый богатый игрок получает из Банка 300B, второй по богатству — 200B, остальные — по 100B. (Все игроки с одинаковой суммой получают одинаковую награду.) |

## Смыслы и редакторские уточнения

- **EV-167:** добора нет именно за два события, разрешённых «Выгоранием». Если «Кофе» даёт разыграть третье, за него добор сохраняется; при «Двойном доборе» это два события. Вампир не заменяет отсутствующее право на добор за первые два события. Вариант с вычитанием двух карт из общего количества не принят.
- **EV-343:** принят предложенный короткий текст про один следующий платёж по эффекту события. Это не перехват всех платежей одного события и не всех будущих взносов по кредиту. Выбирать плательщика заранее не требуется.
- **EV-129:** автор предпочёл привычную формулу «самый богатый / второй по богатству / остальные» предложению «с наибольшей суммой / со следующей меньшей». Участники с одинаковой суммой получают одинаковую награду, а не делят её. В его примечании «получают оба» слово «оба» обобщено на любое число игроков. Остальная формулировка сохранена; отдельные дополнительные правила ранжирования не вводятся.

## Удаление EV-341

**EV-341 «Наследство» удалена по прямому решению автора.** Её предложенный немедленный вариант дублировал EV-025 «Делегирование». EV-025 сохраняет свой ID, название, количество и эффект; переименование в «Наследство» не утверждено.

Последний текст перед удалением:

> Выберите игрока. При следующей смене своего статуса передайте ему прежний вместо сброса.

Прежняя заготовка иллюстрации:

> Сюжет пока не выбран. Эффект утверждён 2026-10-04; будущая иллюстрация не должна добавлять игровых условий.

Строка исключена из действующих RU/EN/универсального шаблона, общей описи и списка иллюстраций. История и исходные файлы сохранены. ID EV-341 не использовать повторно.

Автор считает вопросы этой порции согласованными; исторические незавершённые варианты не переносить в текущие эффекты.
