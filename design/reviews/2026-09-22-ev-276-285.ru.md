# EV-276–285: эффекты и авторские смыслы — 2026-09-22

Продолжение: [EV-286–296 утверждены, названия монеты обменены](2026-09-22-ev-286-296.ru.md). EV-285 теперь называется «Монета устала», EV-290 — «Монета отдыхает». Прежние названия и вопросы ниже сохраняют историю этой записи.

Автор утвердил эту десятку с уточнениями к EV-276, EV-279, EV-283 и EV-285. Рабочая ветка — `events-254-onward-review`, родительский коммит `58a1741b54725d13f63021323db89be23ecfc44d`. Следующая десятка на обсуждение — **EV-286, EV-288–296**; EV-287 ранее удалена. Слияние не поручено.

## Утверждённые эффекты

| ID | Название | Эффект |
| --- | --- | --- |
| EV-276 | Удача | Возьмите новое событие и 200B из Банка. |
| EV-277 | Ограбление | Заберите у выбранного игрока 300B. |
| EV-278 | Конфискация | Заберите случайное событие из руки выбранного игрока. |
| EV-279 | Идеальный шторм | Каждый игрок платит 200B в Банк и сбрасывает два события из руки. |
| EV-280 | Союз | Вы и выбранный другой игрок получаете по 200B из Банка. |
| EV-281 | Денежный дождь | Каждый игрок получает 100B из Банка. |
| EV-282 | Бандит | Заберите по случайному событию из рук двух других игроков. |
| EV-283 | Казино | Назовите ставку до 600B и бросьте монету: UP — возьмите эту сумму из Банка; W — отдайте её в Банк. |
| EV-284 | Благотворительность | Самый богатый игрок отдаёт 500B самому бедному. |
| EV-285 | Монета отдыхает | Если монета не будет задействована в этом месяце, возьмите 300B из Банка. |

## Решения о механиках

- **EV-276:** одно событие по эффекту плюс одно при обычном доборе и 200B. Именно такой результат автор выбрал вместо прежних трёх карт по эффекту. «Новое событие» означает взятие из колоды событий; из чужой руки или сброса источник нужно называть явно. Термин уже использован в этой утверждённой формулировке; глобальной замены на всех картах и изменения правил A5 не делали. Ограничения добора по другим действующим эффектам сохраняются.
- **EV-279:** каждый игрок теряет деньги и сбрасывает два события, выбирая их сам. Автор намеренно усилил потерю карт, поскольку в игре много добора. Ожидаемое влияние на баланс — авторская гипотеза, не результат игровых испытаний. Банкротство при денежной части не отменяет сброс.
- **EV-283:** автор прямо разрешает назвать ставку больше имеющихся BABLOS. Предоплаты нет, наличие полной ставки не требуется. Проигрыш — обязательный платёж с обычным банкротством. Пример автора: имея 100B, можно поставить 600B и при W отдать только свои 100B; при UP получить 600B из Банка. При наличии хотя бы 600B игрок покрывает любую разрешённую ставку целиком. Не добавлять требование обеспеченной ставки под видом согласования с общим правилом полной оплаты эффекта: это уничтожит подтверждённый замысел. Сочетания с другими действующими эффектами могут менять последствия; авторский пример не является универсальным расчётом риска.
- **EV-284:** похожие эффекты сравнить во втором круге; сейчас не заменять и не удалять. Для сравнения, EV-045 раздаёт по 100B от богатейшего всем, EV-016 позволяет беднейшему собрать по 100B с остальных, здесь прямой перевод 500B от богатейшего беднейшему.
- **EV-285:** автор хочет отдых монеты целый текущий месяц и просит исправить только грамматику и пунктуацию предложенного предложения. Это заменяет прежнюю проверку исключительно уже состоявшихся бросков при розыгрыше. Из слов «в этом месяце» и авторского «целый месяц» следует проверка всего текущего месяца, включая время до карты, с наградой по его окончании. Не заменять на «до конца месяца» с проверкой только оставшегося времени. «Задействована» шире броска: статус ST-006 использует монету в угадывании руки, EV-027 — на лбу. Это редакторское прочтение утверждённого текста, а не отдельно согласованная новая оговорка на карточке. Не вводить исключений для этих применений. Предстоящая EV-290 запрещает использование монеты; её взаимодействия ещё обсуждаются.

## Авторские смыслы и ориентиры для иллюстраций

- **EV-276 «Удача»:** без удачи в такой игре делать нечего; приятное сочетание нового события и денег.
- **EV-277 «Ограбление»:** финансовая атака средней силы.
- **EV-278 «Конфискация»:** знакомство с неприятным термином; автор надеется, что игрокам он не пригодится в жизни.
- **EV-279 «Идеальный шторм»:** плохие события накладываются друг на друга. Потеря денег и двух событий должна ощущаться болезненно, но выбор сброса позволяет расстаться с наиболее слабыми картами.
- **EV-280 «Союз»:** побуждение к кооперации и помощи друг другу ради успеха.
- **EV-281 «Денежный дождь»:** приятное событие после многочисленных налогов; похожие карты различить позже.
- **EV-282 «Бандит»:** одновременная атака двух игроков — настоящий бандитизм.
- **EV-283 «Казино»:** мини-игра внутри большой игры. Возможность ставки без достаточного обеспечения и банкротства — намеренная находка автора, не ошибка баланса, подлежащая автоматическому исправлению.
- **EV-284 «Благотворительность»:** принудительная благотворительность как смешной абсурд. Похожие карты проверить в следующем круге.
- **EV-285 «Монета отдыхает»:** монета устать не может, но в этой игре от работы устаёт даже она, как человек. Важен настоящий отдых в течение целого месяца.

## Границы обновления

Общие правила RU/EN, PDF A5, состав колоды, ID и прототипы не менялись. Английские карточные таблицы остаются непереведёнными. Предложения следующей десятки не утверждены и в эффекты не внесены. Вопрос порядка добора при дополнительных розыгрышах остаётся в предыдущей записи; «Кофе» здесь не редактировалась.
