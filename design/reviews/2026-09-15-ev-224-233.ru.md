# EV-224–233: вычитка 2026-09-15

Только решения текущей вычитки и обсуждаемые игровые механики. Основной каталог: [русские игровые карты](../../game/ru/cards/events.md).

- **EV-107 «Курс BABLOS».** Автор заменил группы по семь банкнот группами по восемь: UP — 100B за полную восьмёрку, W — отдать каждую восьмую банкноту. Изменены обе стороны, снижая величину как выигрыша, так и потери. Прежняя семёрка больше не действует. Считать банкноты до выплаты, без повторного начисления на полученное.
- **EV-224 «Джекпот».** Бросать до первого W, получать 100B за каждый UP; W прекращает броски, уже полученное остаётся. Автор подчёркивает редкость большой серии при неограниченном правилами числе удачных бросков. Это не гарантирует неограниченность физического Банка: вопрос его нехватки остаётся общим. При честной монете шанс хотя бы одного UP — 50%, пяти подряд — 1/32; крупный выигрыш редок, но небольшая выплата не «почти невозможна». Обычный добор сохраняется.
- **EV-225 «Выходные».** Автор разрешил выбрать между «Выходными» и «Каникулами»; выбраны «Выходные», ориентир английской локализации — Weekend, перевод карточки ещё не выполнен. Выплата 100B удалена, остаётся пропуск ходов до конца текущего месяца. Обычная зарплата при конце месяца не отменяется самой этой картой. Обрыв оставшихся розыгрышей текущего хода автор отдельно не подтвердил; не объявлять решённым. Новая отдельная карта «Праздник» лишь обсуждается, ID ей не присвоен.
- **EV-226 «Дивиденды».** Выплата 100B за каждые девять своих банкнот вместо семи; только полные группы, исходное количество до выплаты. Автор хочет уменьшить денежное ускорение партии. Смысл — деньги приносят деньги.
- **EV-227 «Стресс».** Одна игровая карта по эффекту и обычный добор за розыгрыш отдельно. Авторская шутка — стресс присутствует даже в игре.
- **EV-228 «Случайная находка».** 100B из Банка, короткая небольшая прибыль; формулировка вычитана без изменения механики.
- **EV-229 «Повышение».** Двойная зарплата до смены статуса, без первоначальной цены. Отсутствие права на зарплату не создаёт выплаты. Смысл — повышение дохода в жизни.
- **EV-230 «Бонус».** Теперь 100B за полную тройку игровых карт в руке, а не за пару. Считать после выкладывания карты и до обычного добора. EV-121 «Пассивный доход» сохраняет пары. Авторская отсылка — игровые бонусы; пассивный доход намеренно приятнее.
- **EV-231 «Криптовалюта».** Полная оплата 200B, три броска, 1100B только при трёх UP. Оплата не возвращается при неудаче. Для честной монеты шанс 1/8, чистый результат успеха +900B, неудачи −200B. Авторский образ — рискованный актив, не финансовая рекомендация.
- **EV-232 «Всё проходит».** Утверждено окончание месяца после каждого хода разыгравшего, впервые после текущего хода целиком. Прежняя привязка месяца заменяется. Авторская отсылка — мудрость Соломона о преходящем.
- **EV-061 «Високосный год» — предложение, ещё не принято.** Автор спросил о переносе конца месяца перед каждым своим ходом, чтобы развести с EV-232. Текущий текст EV-061 пока оставлен «после». Возможная редакция: «Теперь месяц заканчивается перед каждым вашим ходом». Она должна заменять прежнюю привязку целиком и впервые срабатывать перед следующей очередью разыгравшего, а не задним числом перед уже начавшимся ходом. Проверить вместе с пропусками: предлагается считать наступление очереди даже при пропуске. Зарплата, платежи, истечение запретов и сроки «Вируса» тогда наступают до действия игрока; победа от выплаты может завершить партию до его карты. Хакер по-прежнему может приблизить очередь окончания месяца. При исключении носителя передавать преемнику и привязку, и положение «перед/после»; действующая строка RU/EN про исключение пока охватывает только «после» и потребует согласованного уточнения. Эти детали — анализ и предложения, не действующие изменения правил.
- **EV-233 «Справедливость».** Сам разыгравший исключён из получателей удвоенной выплаты: получает самый богатый из остальных игроков. Это выбор богатейшего среди остальных, а не отмена второй выплаты, если разыгравший богатейший за всем столом. До 300B разыгравшему, вдвое больше выбранному по богатству получателю; собственная выплата не меняет богатейшего среди остальных. Авторская сатира на капитализм: обладатель капитала получает больше. Можно сознательно взять 100B, чтобы ему досталось 200B вместо 600B.
- **Идея новой карты «Праздник».** Автор просит предложение, а не добавление утверждённой карты. В каталоге уже есть общие фиксированные выплаты: EV-041, EV-191 и EV-281 по 100B; EV-113 по 200B; EV-181 по 300B; EV-008 по 400B. Новая общая выплата 500B была бы отдельной суммой, но внесла бы 1500–3000B за стол на 3–6 игроков. Альтернатива для обсуждения — каждому по 100B и одной игровой карте: небольшие праздничные деньги и подарок. Простая раздача всем по одной карте уже есть у EV-049 и EV-101. Выбор и новая карта ещё не утверждены.
