# EV-224–233: вычитка 2026-09-15

Только решения текущей вычитки и обсуждаемые игровые механики. Основной каталог: [русские события](../../game/ru/cards/events.md).

- **EV-107 «Курс BABLOS».** Автор заменил группы по семь банкнот группами по восемь: UP — 100B за полную восьмёрку, W — отдать каждую восьмую банкноту. Изменены обе стороны, снижая величину как выигрыша, так и потери. Прежняя семёрка больше не действует. Считать банкноты до выплаты, без повторного начисления на полученное.
- **EV-224 «Джекпот».** Бросать до первого W, получать 100B за каждый UP; W прекращает броски, уже полученное остаётся. Автор подчёркивает редкость большой серии при неограниченном правилами числе удачных бросков. Это не гарантирует неограниченность физического Банка: вопрос его нехватки остаётся общим. При честной монете шанс хотя бы одного UP — 50%, пяти подряд — 1/32; крупный выигрыш редок, но небольшая выплата не «почти невозможна». Обычный добор сохраняется.
- **EV-225 «Выходные».** Название выбрано автором из предложенных вариантов, ориентир перевода — Weekend. Выплата 100B удалена. Все пропускают ходы до конца текущего месяца, а текущий ход разыгравшего тоже немедленно завершается: дополнительные розыгрыши прекращаются. Обычный добор за уже сыгранные карты сохраняется по общим правилам и с учётом действующих запретов. Сама карта не отменяет обычную зарплату при окончании месяца. Если месяц заканчивается после текущего хода разыгравшего, «Выходные» закончатся вместе с этим месяцем; если перед его очередью, пропуски длятся до соответствующей границы.
- **EV-226 «Дивиденды».** Выплата 100B за каждые девять своих банкнот вместо семи; только полные группы, исходное количество до выплаты. Автор хочет уменьшить денежное ускорение партии. Смысл — деньги приносят деньги.
- **EV-227 «Стресс».** Одно событие по эффекту и обычный добор за розыгрыш отдельно. Авторская шутка — стресс присутствует даже в игре.
- **EV-228 «Случайная находка».** 100B из Банка, короткая небольшая прибыль; формулировка вычитана без изменения механики.
- **EV-229 «Повышение».** Двойная зарплата до смены статуса, без первоначальной цены. Отсутствие права на зарплату не создаёт выплаты. Смысл — повышение дохода в жизни.
- **EV-230 «Бонус».** Теперь 100B за полную тройку событий в руке, а не за пару. Считать после выкладывания карты и до обычного добора. EV-121 «Пассивный доход» сохраняет пары. Авторская отсылка — игровые бонусы; пассивный доход намеренно приятнее.
- **EV-231 «Криптовалюта».** Полная оплата 200B, три броска, 1100B только при трёх UP. Оплата не возвращается при неудаче. Для честной монеты шанс 1/8, чистый результат успеха +900B, неудачи −200B. Авторский образ — рискованный актив, не финансовая рекомендация.
- **EV-232 «Всё проходит».** Утверждено окончание месяца после каждого хода разыгравшего, впервые после текущего хода целиком. Прежняя привязка месяца заменяется. Авторская отсылка — мудрость Соломона о преходящем.
- **EV-061 «Високосный год» — утверждено.** Теперь месяц заканчивается перед каждым ходом разыгравшего; прежняя привязка заменяется целиком, базовое правило после хода раздающего для игры без этого эффекта не меняется. Текущий ход уже начался, поэтому первое срабатывание перед следующей очередью разыгравшего, без ретроактивной выплаты. Пас и вынужденный пропуск не останавливают смену месяцев: перед наступившей очередью проходят зарплата и прочие месячные последствия. Дополнительные розыгрыши внутри одного хода не создают новых начал хода. Автор считает эти следствия понятными из общих правил и просит не добавлять их на карту или расширять правила. При исключении носителя случай оставлен участникам: сам автор считает логичным передать следующему по очереди игроку ту же привязку «перед/после». Отдельное обязательное правило для этого случая не вводится. Текущие полные правила RU/EN не расширяются; их существующая строка об исключении описывает прежний случай окончания месяца после хода. Анализ взаимодействий с зарплатой, победой, «Вирусом» и временными ограничениями остаётся в разработке, без новых подсказок на карточке.
- **EV-233 «Справедливость».** Сам разыгравший исключён из получателей удвоенной выплаты: получает самый богатый из остальных игроков. Это выбор богатейшего среди остальных, а не отмена второй выплаты, если разыгравший богатейший за всем столом. До 300B разыгравшему, вдвое больше выбранному по богатству получателю; собственная выплата не меняет богатейшего среди остальных. Авторская сатира на капитализм: обладатель капитала получает больше. Можно сознательно взять 100B, чтобы ему досталось 200B вместо 600B.
- **EV-314 «Праздник» — добавлена.** Автор утвердил всем по 100B из Банка и по одному событию из колоды. Один экземпляр; ID EV-313 остаётся удалённым и не переиспользуется. Это отдельная карта от EV-225 «Выходные», без пропуска ходов. Карта, полученная по эффекту, дополняет обычный добор разыгравшего; при отсутствии запретов он получает два события, остальные по одному. Английская строка и шаблон перевода пока пустые. Прежние варианты по 500B и только по одной карте не приняты.
