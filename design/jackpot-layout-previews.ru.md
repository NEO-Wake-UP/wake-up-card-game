# «Джекпот» — две пробы нового расположения текста

23 октября 2026 · EV-181 · русская версия. По последнему поручению автора сохраняем только текстовые изменения: PNG в эту порцию GitHub не входят. Ниже зафиксировано обсуждение созданных в чате проб. Полный текст соответствует [каталогу событий](../game/ru/cards/events.md). PNG созданы встроенной генерацией изображений: первая проба по текстовому заданию, вторая — стилизация первой с сохранением эффекта.

## Читаемость и компоновка

Автор одобрил этот простой образец как проверку своего замысла: название и полный эффект в двух соединённых рамках сверху; белая кайма; рисунок снизу по оставшемуся месту.


## Мультяшный хайтек, Новый год

Второй вариант добавляет золотые и ледяные акценты, подсветку рамок и праздничные цвета, сохраняя крупный текст. Автор запросил ориентир 70% читаемости / 30% стиля. Конкретный результат пока является предложением, не финальным утверждённым оформлением серии.


Оба PNG — 1060 × 1484 пикселя. Для первой авторской проверки достаточно отобразить карточку на мониторе в размере 63 × 88 мм, проверенном линейкой. Это растровые пробы с вписанным текстом; редактируемые печатные мастера и полный комплект ещё не подготовлены. Крупный текст и его смысл имеют приоритет над иллюстрацией.

Текст обоих изображений визуально сверен с действующим EV-181. Художественная основа — существующая идея денежного шара-дворца из [подборки событий](event-illustration-ideas.ru.md). Сами сцены в подборке сохранены. Исходные прототипы других карт не изменены.
