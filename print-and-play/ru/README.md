# Русский набор для печати

[Правила WAKE UP — PDF A5](WAKE_UP_rules_RU_A5.pdf): **сохранённая редакция 2026-09-23; не включает изменения от 2026-09-27** о доборе нескольких событий и сбросе без розыгрыша. Автор прямо попросил пока не обновлять PDF. Актуальный текст — [правила на GitHub](../../game/ru/rules.md). PDF: одна страница 148 × 210 мм, основной шрифт 10,5 пт; печать в масштабе 100% («Фактический размер»). Читаемость редакции 2026-09-20 подтверждена автором на бумаге; вёрстка от 2026-09-23 проверена на экране. Это макет для проверки, без производственных вылетов. Новая вёрстка и проверка текста после уточнений ещё не проводились.

Полный набор **не собран**: PDF карт и готового архива пока нет. Есть [тексты карт](../../game/ru/README.md), [прототипы](../../assets/README.md) и [пустые рамки](../../templates/cards/README.md). Для полного набора ещё нужно согласовать состав, закончить иллюстрации, сверстать листы и сделать пробную печать.

Перед следующим печатным выпуском синхронизируйте PDF с правилами RU и проверьте вёрстку. Для текущей правки прежнее требование одновременно обновлять PDF отменено прямым указанием автора. [План состава набора](../README.md).
