# Русский набор для печати

[Правила WAKE UP — PDF A5](WAKE_UP_rules_RU_A5.pdf): **актуальная редакция 2026-10-01**, текст совпадает с [русскими правилами на GitHub](../../game/ru/rules.md).

- Одна страница **148 × 210 мм**; основной шрифт Liberation Sans **10 пт**, интерлиньяж 11 пт; поля 6,5 мм.
- Крупный заголовок слева; справа красная квадратная рамка с тремя строками о числе игроков, времени и возрасте и векторными пиктограммами.
- Печатать на A5 в масштабе **100% / «Фактический размер»**, без автоматического вписывания или уменьшения.
- Текст PDF сверен с Markdown, страница отрисована и просмотрена. Предыдущую редакцию автор проверил на бумаге; новая пока проверена на экране.
- Это макет правил без производственных вылетов, а не готовая развёртка коробки.

## Обновление файла

[Скрипт вёрстки](../../scripts/build_rules_a5.py) читает правила напрямую из Markdown. Требуются Python, ReportLab и шрифты Liberation Sans Regular/Bold (TTF). Запуск из корня репозитория:

```bash
python3 scripts/build_rules_a5.py
# Если шрифты установлены в другом месте:
python3 scripts/build_rules_a5.py --font-dir /path/to/fonts
```

После изменения правил пересоберите PDF и проверьте текст и отрисованную страницу. Скрипт прекращает работу, если текст не помещается на A5: не уменьшайте шрифт или не сокращайте правила без согласования с автором. [Последние решения и параметры вёрстки](../../design/reviews/2026-10-01-rules-a5-and-continuity.ru.md).

Полный набор **не собран**: PDF карт и готового архива игры пока нет. Есть [тексты карт](../../game/ru/README.md), [прототипы](../../assets/README.md) и [пустые рамки](../../templates/cards/README.md). Для полного набора ещё нужно согласовать состав, закончить иллюстрации, сверстать листы и сделать пробную печать. [План состава набора](../README.md).
