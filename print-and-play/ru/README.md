# Русский набор для печати

[Правила WAKE UP — PDF A5](WAKE_UP_rules_RU_A5.pdf): одна страница 148 × 210 мм, основной шрифт 10,5 пт. Текст совпадает с [правилами на GitHub](../../game/ru/rules.md), утверждёнными автором 2026-09-20 и уточнёнными 2026-09-23. Печатайте в масштабе 100% («Фактический размер»). Автор подтвердил хорошую читаемость редакции 2026-09-20 на бумаге. Текущая редакция включает [новую границу месяца](../../design/reviews/2026-09-23-month-before-dealer.ru.md): перед каждой очередью хода раздающего, включая первую и пропуски хода. Основной шрифт 10,5 пт сохранён, интервалы между абзацами немного сокращены. Обновлённая вёрстка проверена на экране, повторная бумажная проба ещё не проводилась. Это макет правил для проверки, без производственных вылетов.

Полный набор **не собран**: PDF карт и готового архива пока нет. Есть [тексты карт](../../game/ru/README.md), [прототипы](../../assets/README.md) и [пустые рамки](../../templates/cards/README.md). Для полного набора ещё нужно согласовать состав, закончить иллюстрации, сверстать листы и сделать пробную печать.

При изменении русского текста обновляйте правила и PDF вместе, сохраняя одинаковые формулировки. [План состава набора](../README.md).
