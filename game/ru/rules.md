# WAKE UP

**3–6 игроков / 33–99 минут / 9–99 лет**

## КОМПЛЕКТ

**BABLOS** — 300 банкнот по 100B; **СТАТУС** — 34 фиолетовые карты; **СОБЫТИЕ** — 331 голубая карта; **МОНЕТА** — 1 (золотая).

## ПОДГОТОВКА

Перемешайте статусы, раздайте каждому игроку по одному лицом вверх. Событие **«WAKE UP»** положите под низ перемешанной колоды событий. Раздайте каждому по **5 событий** лицом вниз. Положите BABLOS в **центр**е стола — это **Банк**.

## ХОД ИГРЫ

Эффекты статусов и событий имеют приоритет над правилами. Игрок, подготовивший игру, — **Бывалый**. Он ходит первым, далее — по часовой стрелке.

Игра делится на **месяцы**. В конце каждого игроки получают из Банка **100B зарплаты**. Перед каждой очередью хода **Бывалого**, **включая первую**, заканчивается месяц и начинается новый — даже если он пропускает ход.

В свой ход выберите одно действие:

- **Разыграть одно событие:** выложите его, выполните эффект и сбросьте. Затем возьмите новое событие из колоды — это **добор**. (Если по эффектам разыгрываете несколько событий за ход, добор за каждое — после розыгрыша последнего.)
- **«ПАС»:** добровольно пропустите ход без добора.

**Важно:**

- После сброса события без розыгрыша добора нет.
- При смене статуса сбросьте прежний; эффект нового можно применить сразу.
- BABLOS, статусы и события — **личные**. Передавать их или сбрасывать **карты без розыгрыша** можно только по эффектам.
- Если для применения эффекта требуется оплата, нужна **полная сумма**. Если BABLOS не хватает на обязательный платёж, вы — **банкрот**. Отдайте **весь BABLOS**: остаток этого платежа списывается, **банкротство заканчивается**. Продолжайте играть.
- Две пустые карты заполните своими идеями или исключите из игры.

## ОСНОВНАЯ ПОБЕДА (выберите режим перед игрой)

**По окончании любого хода** предъявите указанную сумму или больше:

- **Каждый сам за себя (3–6 игроков):** 4400B — «Я олигарх!»
- **Двое против двух (4 игрока):** 8000B на команду — «Мы миллионеры!»
- **Трое против трёх (6 игроков):** 10800B на команду — «Мы миллиардеры!»

(О другой сумме для победы можно договориться до начала игры.)

## ЛЕГЕНДАРНАЯ ПОБЕДА

Разыграйте событие **«WAKE UP»** в свой ход и бросьте монету:

- **WAKE:** вы проснулись и победили! Раздайте проигравшим свои BABLOS.
- **UP:** это был сон. Начните игру заново!

**Если неясно — решайте сами.** Бла-бла-бла… Давайте играть!
