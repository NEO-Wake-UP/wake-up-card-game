# Карты статуса — русский текст

Статус: первая группа ST-001–011 утверждена 2026-09-22; [решения и авторские смыслы](../../../design/reviews/2026-09-22-st-001-011.ru.md). Следующая группа — ST-012–022. ST-013 и ST-019 ранее обновлены по решению автора 2026-09-15; остальные статусы ещё предстоит вычитать. 32 статуса и пустая карта ST-005. Исходная нумерация сохранена; эффект ST-005 оставлен пустым, без многоточия. В эффектах деньги игроков обозначаются как BABLOS, суммы — как `100B`, сторона Wake монеты — как `W`.

Описания картинок отделены в [задания художнику](../../../design/status-art-briefs.ru.md). Количество экземпляров — в [общем составе](../../deck.md).

| ST-001 | Наследник | При получении этого статуса возьмите 700B из Банка. |
| ST-002 | Сын чиновника | Вы всегда получаете двойную зарплату. |
| ST-003 | Супермодель | Раз в месяц заберите у выбранного игрока 100B за «красивые глаза». |
| ST-004 | Собака | Не получаете зарплату и не платите налоги. Раз в месяц погавкайте: если другой игрок засмеётся, возьмите 100B из Банка. |
| ST-005 | Пустая карта статуса для заполнения игроками |  |

| ST-007 | Коррупционер | Раз в месяц заберите у выбранного игрока 100B. |
| ST-008 | Бездомный | Не получаете зарплату и не платите налоги. Раз в два месяца получайте 100B пособия из Банка. |

| ST-018 | NPC | Каждый второй месяц за вас вашими картами ходит один из соседних игроков, если вы после такого хода говорите: «Я так и хотел» получаете 100B |
| ST-019 | Городской сумасшедший | Каждый месяц выдвигает теории о том, что игра похожа на жизнь. |
| ST-020 | Король | все игроки обращаясь к вам говорят «ваше величество», иначе платят вам 100B штраф, но не чаще чем раз в месяц. (Пассивный навык: Не платит налоги.) |
