# Карты статуса — русский текст

Статус: ST-001–022 утверждены в первой вычитке 2026-09-22; [последние решения и авторские смыслы](../../../design/reviews/2026-09-22-st-012-022.ru.md). Следующая группа — ST-023–033. Вариант ST-004 с пометкой «Пассивный навык» пока на согласовании. 32 статуса и пустая карта ST-005. Исходная нумерация сохранена; эффект ST-005 оставлен пустым, без многоточия. В эффектах деньги игроков обозначаются как BABLOS, суммы — как `100B`, сторона Wake монеты — как `W`.

Описания картинок отделены в [задания художнику](../../../design/status-art-briefs.ru.md). Количество экземпляров — в [общем составе](../../deck.md).

| ID | Название | Эффект |
| --- | --- | --- |
| ST-001 | Наследник | При получении этого статуса возьмите 700B из Банка. |
| ST-002 | Сын чиновника | Ваша зарплата всегда двойная. |
| ST-003 | Супермодель | Раз в месяц заберите у выбранного игрока 100B за «красивые глаза». |
| ST-004 | Собака | Не получаете зарплату и не платите налоги. Раз в месяц погавкайте: если другой игрок засмеётся, возьмите 100B из Банка. |
| ST-005 | Пустая карта статуса для заполнения игроками |  |
| ST-006 | Игрок | Раз в месяц спрячьте монету в одной из рук. Выбранный другой игрок угадывает руку: угадал — он получает 100B из Банка; нет — вы. |
| ST-007 | Коррупционер | Раз в месяц заберите у выбранного игрока 100B. |
| ST-008 | Бездомный | Не получаете зарплату и не платите налоги. Раз в два месяца получайте 100B пособия из Банка. |
| ST-009 | Трансформер | При получении статуса выберите один эффект: 1) Возьмите 600B из Банка. 2) Получайте 100B к зарплате до смены статуса. 3) Раз в два месяца бросайте монету: UP — возьмите 200B из Банка; W — ничего. |
| ST-010 | Рабочий | Вас всё устраивает. |
| ST-011 | Путешественник | Раз в три месяца можете поменяться местами за столом с выбранным игроком. |
| ST-012 | Лентяй | За каждый пропущенный ход получайте 100B из Банка. |
| ST-013 | Вор | Не получаете зарплату. Раз в три месяца сбросьте случайное событие из руки выбранного другого игрока и возьмите 400B из Банка. |
| ST-014 | Бариста | Когда любой игрок разыгрывает «Кофе», получайте 100B из Банка. |
| ST-015 | Сосед | Раз в два месяца займите у одного из соседей 100B. Возвращать не нужно. |
| ST-016 | Разработчик игр | Не получаете зарплату. За каждое использование монеты в игре получайте 100B из Банка, но не больше 400B за месяц. |
| ST-017 | Стартапер | Раз в месяц бросайте монету: UP — возьмите 300B из Банка; W — отдайте 100B в Банк. |
| ST-018 | NPC | Каждый второй месяц один из ваших соседей (на их усмотрение) в ваш ход разыгрывает ваше событие. Скажите после этого «Я так и хотел» и получите 100B из Банка. |
| ST-019 | Городской сумасшедший | Каждый месяц выдвигайте новую теорию о сходстве игры с жизнью. |
| ST-020 | Король | За обращение к вам без «Ваше Величество» берите с нарушителя 100B. (Пассивный навык: не платите налоги.) |
| ST-021 | Хакер | После своего хода можете изменить направление ходов на противоположное. |
| ST-022 | Шопоголик | Вместо зарплаты берёте новое событие. |
| ST-023 | Манипулятор | Раз в месяц может поменять своё событие на случайное другого игрока. |
| ST-024 | Немой | Не может говорить в течение игры, объясняется жестами и звуками, за это раз в месяц получает пособие 100B к зарплате. |
| ST-025 | Благотворитель | Раз в месяц даёт любому игроку 100B и берёт себе 200B из Банка. |
| ST-026 | Хозяин судьбы | Поменяйте эту карту статуса на любую из 3х верхних карт статуса. |
| ST-027 | Оракул | При взятии события сам выбирает его из двух верхних. |
| ST-028 | Банкир | Выдаёт и получает BABLOS из Банка игрокам. За это получите 100B к зарплате. |
| ST-029 | Барахольщик | Раз в 2 месяца берёт случайное событие из сброса. |
| ST-030 | Комментатор | Получите 100B к зарплате если прокомментируете все ходы игроков. |
| ST-031 | Философ | Раз в месяц, может отказаться от зарплаты и получить событие. |
| ST-032 | Донор | Раз в месяц может сбросить событие без добора и получить в Банке 300B. |
| ST-033 | Джокер | использует эффект карты статуса любого из соседних с ним игроков, может чередовать. |
