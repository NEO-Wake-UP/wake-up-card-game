# English edition

**Source update, 2026-09-30:** [approved rules](../../design/reviews/2026-09-30-final-rules.ru.md) introduce the Veteran, explicitly define replacement draws and the end of bankruptcy, allow nonverbal passing, and list player counts for each mode. The final event follows the new ending text. Other approved effects are unchanged, including Agony’s original-hand scope and permitted event gains through effects. Card translation fields remain pending.

Status: **work in progress**, not a complete playable English release.
