# Шаблон оформления правил / Rules background

[WAKE_UP_rules_blank.png](WAKE_UP_rules_blank.png) — пустой фон для заполнения правилами на любом языке, загруженный автором 5 октября 2026 года. Размер **1051 × 1496 пикселей**. Изображение сохранено без изменений.

Открой PNG в Affinity, Photoshop или другом редакторе и добавь перевод отдельными текстовыми слоями. Это растровый фон; редактируемых текстовых слоёв в самом PNG нет. Текст для перевода находится в [русских правилах](../../game/ru/rules.md), порядок подготовки перевода — в [руководстве](../translation/README.md).

Примеры заполнения: [русский PNG](../../print-and-play/ru/WAKE_UP_rules_RU.png) и [английский PNG](../../print-and-play/en/WAKE_UP_rules_EN.png). Готовые языковые версии размещаются в `print-and-play/<код-языка>/`.

Text-free rules background supplied by the author. Add the translated rules as separate text layers, then export into the appropriate language folder. The PNG itself is a flattened raster image.
