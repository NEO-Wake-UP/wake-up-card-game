# Blank card layouts / Пустые макеты карт

- [Event card / Событие](event-blank.svg)
- [Status card / Карта статуса](status-blank.svg)

Two editable SVG drafting frames, **63 × 88 mm** each. They have separate areas for title, illustration and effect, with no visible text. Use them for handwritten custom cards or as a starting point in a vector editor. The status frame uses gold; the event frame uses blue. These are newly drawn basic frames, not the illustrated style of the existing prototypes.

Две простые редактируемые SVG-рамки размером **63 × 88 мм**, без текста. Сверху — название, в центре — место для картинки, снизу — эффект. Можно вписать свою карту вручную после печати или добавить текст в векторном редакторе. Статус — золотистая рамка, событие — голубая. Это начальные макеты; готовые иллюстрированные шаблоны существующих карт ещё предстоит сделать.

For a single blank, print at 100% / actual size and measure 63 × 88 mm. No crop marks, bleed, backs or sheet imposition are supplied here; prepare those with the final pack. Do not use a browser's fit-to-page setting as a size guarantee.

Для отдельной пустой карты печатайте в масштабе 100% / «фактический размер» и проверьте линейкой. Здесь пока нет вылетов, меток реза, рубашек и раскладки на лист; их подготовим для финального набора. Рамки не являются готовым заданием типографии.

SVG groups: `frame`, `title-area`, `art-area`, `effect-area`. Add editable text layers inside the title/effect areas. For a localized game, keep the illustration and text separate and associate the result with the original card ID.

## Рамки в оформлении «Экономной поездки»

- [Обычный эффект: event-affinity-63x88.svg](event-affinity-63x88.svg) — окно рисунка 54 × 50,5 мм, нижняя плашка 54 × 16 мм.
- [Длинный эффект: event-affinity-63x88-long.svg](event-affinity-63x88-long.svg) — окно 54 × 38,5 мм, нижняя плашка 54 × 28 мм.
- [Пошаговая сборка в Affinity](../../design/affinity-event-card-guide.ru.md) и [идеи иллюстраций](../../design/event-illustration-ideas.ru.md).

Новые векторные заготовки: белая кайма, голубая/сиреневая рамка, кремовая плашка с золотистой обводкой и светлое поле эффекта. Не точная копия исходного прототипа. Открывайте SVG через File → Open, сохраняйте копию в родном формате Affinity. Удалите группу DELETE_ME_HINTS; вставьте PNG внутрь ART_WINDOW и создайте отдельные текстовые рамки.

Страница — 63 × 88 мм. Вылеты 3 мм нужно включить в параметрах Affinity отдельно: SVG не содержит настройки PDF TrimBox. Фон задан с запасом; проверьте после импорта его размеры по руководству. Текст держите внутри безопасной области. Геометрия и рендер проверены, но импорт именно в Affinity и бумажная проба ещё предстоят. Это учебные рамки, не готовый заказ типографии.
