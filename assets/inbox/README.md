# Входящие изображения / Image inbox

Загружай сюда новые картинки WAKE UP, которые потом нужно переименовать и разложить по проекту.

1. Открой [эту папку на GitHub](https://github.com/NEO-Wake-UP/wake-up-card-game/tree/main/assets/inbox).
2. Нажми **Add file → Upload files**, перетащи изображения и сохрани загрузку кнопкой **Commit changes**.
3. Напиши Лису: «Разбери новые изображения в assets/inbox». Если назначение не видно из картинки, добавь ID карты, язык или короткое пояснение.

Можно использовать удобные тебе имена. Для другой версии уже загруженного файла лучше добавить дату или номер, чтобы случайно не заменить предыдущую.

После просьбы Лис переименует и переместит файлы в нужные папки, обновит ссылки и сохранит исходное содержимое изображений. Изменять рисунок, текст или разрешение следует только по отдельному поручению. Эта папка для приёма файлов: загрузка сюда сама по себе не означает утверждения окончательного дизайна.

Готовые правила находятся в [print-and-play](../../print-and-play/README.md), прототипы — в [assets](../README.md), пустые фоны правил — в [templates/rules](../../templates/rules/README.md).

Upload new WAKE UP artwork here, then ask for it to be renamed and sorted. Optional notes: card ID, language and version. Sorting preserves the original image bytes; uploads are not automatically final artwork.
