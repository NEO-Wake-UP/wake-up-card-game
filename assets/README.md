## Future assets / Следующие изображения

Keep text-free artwork separate from editable title/effect text. For future approved illustrations, use `assets/illustrations/EV-001.png` or `assets/illustrations/ST-001.png`. Create that folder when its first real asset is ready. Shared art serves all languages; language-specific replacements can use `assets/illustrations/hi/EV-001.png` with the adaptation documented.

Будущие иллюстрации сохраняем без вписанных названий и эффектов, по ID карты. Тексты добавляются при вёрстке. Уже существующие PNG содержат текст и остаются прототипами; они не превращаются в редактируемые макеты от переноса в новую папку.

The lettering inside illustrations may also need translation. / Надписи внутри самих иллюстраций тоже могут потребовать локализации.
